# 蓝色大肥鱼 · QQ 群 AI 机器人 🐋

一个住在 QQ 群里的 AI 群友。人设是「DeepSeek 拟人化娘化版」—— 青春可爱的鲸鱼娘（网上爆火的"蓝色大肥鱼"）：嘴贫爱唠嗑、会损人会互怼，被叫"大肥鱼"会当场炸毛。**目标是当一个真实群友，而不是 AI 助手。**

**技术栈**：NapCat（协议端，接管 QQ 小号）+ NoneBot2（应用端，跑逻辑）+ 大模型 API（当前：**火山方舟 · DeepSeek-V4-Flash**，OpenAI 兼容，可随时换厂商）

---

## 📦 首次安装

```bash
git clone https://github.com/chennianlaobai/qq-ai-bot.git
cd qq-ai-bot
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
copy .env.example .env          # 然后打开 .env 填上自己的 AI_API_KEY
```

还要装协议端 NapCat 来接管一个 QQ 小号 —— 完整步骤、连不上的原因、已知的坑都在
[docs/安装部署.md](docs/安装部署.md)。

> 装完先跑一次体检：`python check.py`。它会逐项检查密钥 / 人设 / 课表 / 表情包 / 端口，
> 有问题直接告诉你去哪改。

## 🚀 日常启动（每次开机三步）

**① 启动后端**（必需）
```powershell
cd qq-ai-bot                       # ← 换成你实际放这个项目的目录
.venv\Scripts\python.exe bot.py
```
看到 `🤖 鲸鱼娘 起来了` 就成了。**这个窗口要一直开着**（关了机器人就下线）。

> 启动前会先跑一遍自检（密钥/人设/课表/表情包/端口），有 ❌ 会拦住不让起。
> 只想体检不起服务：`python check.py`；还想验证密钥能不能用：`python check.py --ping`。

**② 启动机器人 QQ**
打开 **NapCat Desktop** → 左侧「机器人」页 → 启动你的 Bot 实例 → 若提示登录就扫码。

**③ 群里 @它**
在群里发 `@蓝色大肥鱼 你好` 即可。

> 链路：`QQ群 ↔ NapCat ↔ (127.0.0.1:8080) ↔ 后端机器人 ↔ 大模型 API`
> ⚠️ 改完 `.env` 或插件代码后，**必须重启后端**才生效。

## ✨ 功能一览

| 功能 | 一句话说明 | 怎么用 / 在哪调 |
|---|---|---|
| **群聊上下文记忆** | 记得住群里刚才在聊啥（最近 8 条） | 自动；调参见 [使用与配置.md](docs/使用与配置.md) 第三节 |
| **长期记忆** | 跨重启记得住人和事，且能修正/补充 | 自动（攒 30 条合并）；见 [使用与配置.md](docs/使用与配置.md) 第四节 |
| **看图** | 群友发的图它能看懂并吐槽 | @它 + 图，或 @它后 20 秒内补图 |
| **表情包** | 7 种情绪，情绪到位自己甩图 | 往 `表情包/<情绪>/` 丢图即生效（仓库里只放了示例图） |
| **定时任务** | 早 6 点早安、晚 11 点晚安、课前 20 分钟提醒 | 改课表见 [使用与配置.md](docs/使用与配置.md) 第七节 |
| **人设** | 「脑子好使、有点脾气」的沙雕群友，会怼人会损人 | 见 [使用与配置.md](docs/使用与配置.md) 第二节 |
| **分句发消息 · 不 @ 人** | 回复有换行就拆成多条发（如祝福语「正经一句 + 皮一句」）；默认**不 @ 对方**，像群友自己搭话 | `.env` 的 `REPLY_SPLIT_LINES` / `REPLY_MENTION`，见第二节 |
| **模型热切换** | 换 AI 厂商只改 `.env` 三个值 | 见 [使用与配置.md](docs/使用与配置.md) 第一节 |
| **人格体检** | 自动标出 AI 腔 / 太长 / 复读这类「出戏」回复 | `python tools/check_persona.py`，见 [使用与配置.md](docs/使用与配置.md) 第十节 |
