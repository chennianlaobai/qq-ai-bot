# 安装部署 & 排错

> 换新电脑 / 重装时才需要看本文档。日常使用见 [使用与配置.md](使用与配置.md)。

---

## 一、首次安装

### A. 装 NapCat（协议端）

推荐用 **NapCat Desktop**（图形化，可避开 shell 一键包的各种坑）：

1. 到 `https://github.com/NapNeko/NapCatQQ-Desktop/releases` 下载 `NapCatQQ-Desktop-x64.msi` 安装
2. 打开后进「组件管理 → 协议端」，安装 **NapCat** 组件
3. 进「机器人」页，**创建实例**：
   - QQ 账号：填**小号**号
   - 底座类型：NapCat（不带 QQ GUI）
   - 运行宿主：本机
   - 掉线自动重启：建议**打开**
4. 进「连接」页，新增 **WS 反向客户端**：

   | 字段 | 填什么 |
   |---|---|
   | 连接名称 | 随便（如 `ws-client-01`） |
   | 服务端 URL | `ws://127.0.0.1:8080/onebot/v11/ws` ⚠️ **末尾 `/ws` 不能少** |
   | 鉴权 Token | **留空**（后端未开鉴权） |
   | 连接角色 | **Universal（全双工）** |
   | 消息上报格式 | Array |
   | 心跳间隔 | 30000 |
   | 重连间隔 | 5000 |
   | 开启此连接 | 打开 |

5. 保存 → 启动实例 → 扫码登录小号

> ⚠️ **别点 NapCat 里 QQ 的「更新」**。保持当前这个兼容性好的版本；升到最新版可能触发「文件已损坏」。

### B. 装后端

```powershell
cd qq-ai-bot                       # ← 换成你实际放这个项目的目录
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### C. 验证

```powershell
.venv\Scripts\python.exe -c "import bot"
```
日志里出现 `Succeeded to load plugin "ai_group"` 就说明插件没问题。

## 二、已知的坑（血泪史，务必先看）

| # | 现象 | 原因 | 解决 |
|---|---|---|---|
| 1 | NapCat 一键包 installer 下载 QQ 报 **HTTP 404** | 一键包内置的 QQ 下载链接失效（官方已知 bug） | 从 QQ 官网下 Windows 安装包，放到 `NapCatInstaller.exe` 同目录并**重命名为 `QQ.exe`**，再跑 installer 即可跳过下载 |
| 2 | 启动报**「文件已损坏，请重新安装QQ」** | 新版 QQ 的文件完整性校验拦截 NapCat 注入（shell 一键包对最新 QQ 兼容差） | **改用 NapCat Desktop**（可视化版），它能正常完成下载 + 注入 |
| 3 | WS 连不上 | 地址没写全 | 必须 `ws://127.0.0.1:8080/onebot/v11/ws`，只写 `/onebot/v11` 连不上 |
| 4 | 两边 Token 对不上 | 后端没开鉴权 | 后端没开鉴权时，NapCat 端 Token 也**留空** |
| 5 | 火山模型 ID 报 404 | ID 少了 `-ga-` | 正式版必须是 `deepseek-v4-flash-ga-260731` |
| 6 | 免费模型又慢又报错 | 限流（并发仅 1） | 别用免费模型跑正式群；插件已内置限流自动重试 |

## 三、常见问题排查

| 现象 | 排查 |
|---|---|
| 群里 @了没反应 | ①后端在跑吗 ②NapCat 连接地址对不对（带 `/ws`）③NapCat 实例在线吗 |
| **回复很慢** | 换模型！见 [使用与配置.md](使用与配置.md) 的速度表（避开 `glm-4.7-flashx`） |
| 回复 `[AI 调用失败]` | 多半是限流/网络；已内置自动重试。持续失败就查账户余额 |
| 还是太像 AI / 太傻 | 改 `SYSTEM_PROMPT` 的【怎么聊天】那段；或换更强的模型 |
| NapCat 显示连不上 | 会自动重连（5 秒一次）；先确认后端已启动 |
| 登录二维码过期 | 重启 NapCat 实例刷新二维码，动作快点扫 |
| 定时消息没发出来 | ①后端在跑吗 ②机器人 QQ 在线吗 ③`TARGET_GROUP` 填了吗 |
| 它记不住事 / 记错了 | 看 `memory/长期记忆.json`；想重置就删掉这个文件再重启 |
| 它不发表情包 | 看 `表情包/<情绪>/` 里有没有图（空文件夹 → 退而从根目录挑） |
