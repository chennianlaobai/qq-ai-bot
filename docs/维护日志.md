## 二、待办路线图（Roadmap）

> **优先级**：**P0** = 立刻做（高价值/低成本）｜**P1** = 近期做｜**P2** = 有空再说｜**P3** = 观望（贵或收益不确定）
> **成本**：以「每天 100 次对话 ≈ 8 元/月」为基线；标「0」= 不增加 API 调用。

### A. 人味增强（让"群友感"更真）

| # | 功能 | 效果 | 优先级 | 难度 | 成本 | 状态 |
|---|---|---|---|---|---|---|
| A1 | **打字延迟 + 分段发送** | 回复前随机停 0.5~2 秒，长回复拆成 2~3 条发 → 像真人打字，不再"秒回一大坨" | **P0** | 低 | 0 | 🟡 分段发送已做（#36 拆多条 + #37 去 @），随机打字延迟未做 |
| A2 | **主动发言 / 插话** | 不等 @ 也会自己冒一句（聊到感兴趣的、群里冷场时）—— 从"问答机"变"真群友"的关键一步 | **P0** | 中 | 少量调用 | ⬜ 未做 |
